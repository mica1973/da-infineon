Mobility Tech Talk – Das software definierte Fahrzeug

Haben Sie schon vom software definierten Fahrzeug gehört? Es revolutioniert die Automobilindustrie, indem es Fahrzeuge in Computer auf Rädern verwandelt. Genau wie Ihr Smartphone basiert das SDV auf Software, die seine Funktionen steuert und kontinuierliche Updates sowie Erweiterungen aus der Ferne ermöglicht. Dieser Wandel betrifft jedoch weit mehr als nur die Technologie. Er verändert grundlegend, wie wir Mobilität erleben und nutzen. Marion Heiss, Application Manager für Cockpit-Lösungen, und Timon Busse, Application Manager für Zonencontroller, geben Einblicke, wie innovative Technologien die Mobilität der Zukunft gestalten und vorantreiben.
